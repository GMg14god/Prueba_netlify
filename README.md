# Proyecto Web con Portal Secreto

Este repositorio contiene dos páginas:
1. **`index.html`**: Una página inicial hiper-minimalista ("Sitio en preparación").
2. **`tools.html`**: La suite completa de herramientas para desarrolladores e informáticos (JSON, Base64, Hashes, Chmod, CIDR, Chuleta Git/Linux).

## 🕵️‍♂️ Formas de entrar al panel secreto desde `index.html`

Cualquiera que entre solo verá una pantalla minimalista limpia. Tienes 3 formas de entrar al panel:

1. **El punto secreto:** Haz **3 clics seguidos** sobre el punto final de la frase `"Espacio privado en preparación."`.
2. **Código secreto de teclado:** Escribe las letras `dev` en cualquier parte de la página con el teclado.
3. **Atajo rápido:** Pulsa `Ctrl + Shift + K`.
